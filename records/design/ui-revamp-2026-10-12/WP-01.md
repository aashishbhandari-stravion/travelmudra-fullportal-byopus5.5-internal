## 3. Architect's decisions on the design's open questions (12 October 2026, LD-12)

| Item | Decision | Reason |
|---|---|---|
| LD-09 tokens (design Q-02, D-06) | Option C: UX §7.2 colours, one ink rail, UX type scale, radius, motion, focus ring; keep Atkinson Hyperlegible (deviation D-06). | PLAN LD-09. |

| Q-11 S9 copy | Amend the S9 text to "If [address] can sign in, we are sending a code to it." | Mail is a task after the commit; "we sent" is not yet a fact. |
| Q-04 `/accounts` | Remove `accounts` from the context selector and the work-areas row now. Keep the route until WP-16 moves its content to SA-07 and OP-10, then retire it. | AD-12: an accounting grant is not a context; LD-02 keeps routes until their content has a new home. |
| Q-05 search text in the address | WP-01 links to the existing search pages only. The package that rebuilds each search page (TA-06 in WP-03; SuperAdmin search with SA-04) resolves SH-R06. | A route-model question; not a shell question. |
| Q-06 attention counts | Keep the page-code counters; render them with the D7 rules (a destination with several counted members shows "needs attention", never a sum; an unreadable count shows "Unavailable"). | No Core change in WP-01; a Kind 1 "attention by destination" is a later proposal only if evidence asks for it. |
| Q-07 / D-03 `next` after sign-in | Adopt: a relative path of the same instance only, validated against the route inventory, and authorized again after sign-in by the normal page load (a page out of scope shows SH-02 Denied). | SH-R03. |
| Q-08 / D-13 staff link | No cross-instance link; text names the staff sign-in. | No configuration names the other instance; the staff host is private. |
| Q-09 / STOP-03 code failures | One combined truthful text; no Kind 2 request. | Distinct results would be a new command behavior; the combined text discloses nothing. |
| Q-10 / STOP-02 projection time | Amend LD-08 to the lag form; no request. | PLAN LD-08. |
| Q-12 transitional rail members | Adopt; a unit test lists them. The operator "Services" item stays transitional until WP-07 decides. | LD-02. |
| Q-13 numbers in copy | Remove the OTP lifetime and attempt numbers from the copy. | The copy must not state a configuration value it does not read. |
| Q-14, Q-15, Q-17 | Accept as designed. | Spec-consistent; Q-15 avoids disclosure. |
| Q-16 CSRF refusal link | Link to the sign-in page on the sign-in surface. | The user's task is signing in. |
| Q-18 `Retry-After` constants | Park (P2). | Not user-visible. |
