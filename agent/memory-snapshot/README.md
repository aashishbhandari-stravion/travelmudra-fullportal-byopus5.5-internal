# Snapshot of the Claude project memory (9 October 2026)

Copies of the per-project memory files that Claude Code keeps outside the repository
(`~/.claude/projects/<project>/memory/`). They record the owner's standing decisions and preferences for
TravelMudra: delegated decisions, data privacy, production topology, UI direction, efficiency rules, the
local preview and the UAT deploy script. The design records and the handover diary are the authority; this
snapshot exists so a new machine or account can seed the memory instead of rediscovering it.

Restore: copy the files into the new machine's memory directory for this project (Claude Code creates the
directory on first use), or paste the relevant facts into the first task chat.
